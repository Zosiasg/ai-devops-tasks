# Zadanie 19: Generowanie prostej dokumentacji

## 1. Prompt

> Stwórz dokumentację endpointu GET /api/users w formacie Markdown, zawierającą opis, parametry, przykładowe żądanie i odpowiedź.

## 2. Odpowiedź ChatGPT

Wygenerowano plik `api-docs.md`, zawierający:

1. Opis endpointu `GET /api/users`.
2. Tabelę parametrów `page`, `limit` i `role`.
3. Przykładowe żądanie HTTP.
4. Przykładową odpowiedź JSON.

## 3. Ocena jakości dokumentacji

**Zalety:**
- Przejrzysta struktura Markdown.
- Czytelna tabela parametrów.
- Konkretne przykłady żądania i odpowiedzi.
- Uwzględnienie wartości domyślnych i ograniczeń.

**Ograniczenia:**
- Brak informacji o autoryzacji i kodach błędów.
- Przykładowa struktura odpowiedzi została przyjęta przez AI.
- Dokumentacja wymaga weryfikacji z rzeczywistą implementacją API.
