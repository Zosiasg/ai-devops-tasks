Trzy bardzo popularne narzędzia wykorzystywane w DevOps to:

Git – rozproszony system kontroli wersji umożliwiający śledzenie zmian w kodzie źródłowym i współpracę programistów. Często wykorzystywany wraz z platformami takimi jak GitHub czy GitLab.

Docker – platforma umożliwiająca tworzenie, uruchamianie i zarządzanie aplikacjami w kontenerach, dzięki czemu działają one w przewidywalny sposób w różnych środowiskach.

Kubernetes – system orkiestracji kontenerów, który automatyzuje wdrażanie, skalowanie i zarządzanie aplikacjami kontenerowymi.
